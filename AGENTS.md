## Agent skills

### Orient first

Before changing anything, read `docs/project-state.md` (current state, open work,
known traps) and `docs/web-integration.md` (how the build is delivered, and the
invariants that keep the site and the Earth-state feed sharing one origin safely).
`project-state.md` is a dated snapshot: when it disagrees with the live system,
the live system is right — re-derive with the commands it lists, and correct it.

### Issue tracker

Issues and PRDs are tracked in GitHub Issues for `pearlmuter/TheMarble`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default canonical triage labels. See `docs/agents/triage-labels.md`.
