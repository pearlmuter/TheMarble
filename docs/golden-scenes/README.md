# Orbital-photography golden scenes

These 1600 × 1000 captures are deterministic visual references for issue #12. Every scene uses a fixed UTC instant and camera pose from `src/orbital-golden-scenes.js` and waits for one complete verified Earth state before capture.

| Scene | Primary check |
| --- | --- |
| `daylight.png` | Surface, clouds, ocean, blue limb, bright-scene sky suppression |
| `crescent-earth.png` | Substantially dark night side, city lights, narrow crescent |
| `terminator.png` | Thin day-night transition and warm low-angle illumination |
| `sunrise-limb.png` | Tangent atmosphere and compact Sun optics |
| `visible-sun.png` | Saturated core, restrained bloom, diffraction, and flare |
| `solar-occultation.png` | Complete optical extinction and faint-sky recovery |
| `moon.png` | Physical phase, size, texture orientation, and shared sunlight |
| `milky-way.png` | High-resolution Gaia sky exposure with direct sunlight absent |
